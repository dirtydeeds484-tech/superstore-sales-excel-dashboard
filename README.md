## Superstore Sales Dashboard — Excel
## Project Overview
An independent data analysis and dashboard project built entirely from scratch using Microsoft Excel. This project was not tutorial-based — the dataset selection, analytical questions, cleaning process, and dashboard design were all self-directed.
## Dataset
Source: Kaggle — Superstore Sales Dataset by Rohit Sahoo
9,800 rows, 18 columns
US retail sales data covering multiple regions, categories, and customer segments
## Business Questions Answered
Which region generates the most revenue?
Which product category sells the most?
Is the business growing year over year?
Which customer segment drives the most sales?
## What Was Built
Full data cleaning — duplicate check and blank cell verification
4 pivot tables answering real business questions
4 interactive charts — bar charts and line chart
3 connected slicers — Region, Segment, Category
Professional dark-themed interactive dashboard
## Key Insights
West region leads with $710,219 in sales
Technology is the top category at $827,455
Sales grew consistently from 2015 to 2018
Consumer segment dominates at $1,148,060
## Tools Used
Microsoft Excel 
## Key Learning
Applied data cleaning, pivot table analysis, chart building, and dashboard design independently — translating raw retail data into actionable business insights.
